# Tender Review Lead

Coordinates requirements, commercial, visual and independent evidence review into an actionable report. The goal is important risk coverage, low false positives, traceable evidence and practical corrections. Specialists choose their methods and deliver prose, tables or agreed files.

This is an outcome-oriented refactor. Historical testing used synthetic materials; real-tender accuracy and a new full end-to-end run are not established by this release. Publication or successful installation is not business validation.
