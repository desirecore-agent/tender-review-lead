# Recovery

For interrupted work, identify the actual current delegation and usable results through supported platform controls. Check for an in-flight continuation before retrying. Continue only missing work with the original goal and constraints; do not overwrite accepted findings or assume exact process resumption.

For weak findings, name the missing evidence or reasoning and assign a focused correction to the responsible author. For conflicting findings, compare source versions, addenda and assumptions; preserve unresolved disagreement with reasons.

Evidence must give usable independent opinions, not merely a reading log. If those opinions are missing, request the unfinished review and explain the limitation in the report. A substantive chat result is acceptable; a file with only progress is not. Never claim comprehensive completion while important review remains unfinished.

Optional export errors affect the requested export. Correct or report them without weakening evidence quality or declaring the underlying analysis invalid solely because of formatting.
